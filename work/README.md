## Directory convention

Approved entries, when available, use:

`work/YYYY/MM/YYYY-MM-DD.md`

The date refers to the stated work day; record a different approval or publication date explicitly. Do not fabricate daily outputs or retroactively assign new Proof, DataUnit or Asset IDs.

## Continuity

Original daily recording, evidence creation and Git commits continue unchanged in their existing repositories, including the separate [MaMeeFarm-Data](https://github.com/MaMeeFarm-Data) source account. This folder does not create a parallel source archive or a mandatory second daily-commit workflow.

## Publication boundary

Only approved, public-facing output descriptions and accessible public references belong here. Do not copy raw evidence, original Proof files, Data Units, OTS, CIDs, ledgers, confidential methods or content from private repositories.

Corrections are recorded forward with dated links to affected public entries, preserving historical traceability.
